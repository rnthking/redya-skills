## 2. 怎样输入

粘贴原文的小红书链接，点击「解析」，选择「爆文复刻」。解析完成后，系统展示原文标题和 7 张原图。

在「我的要求」里填写：

```text
换成6张茉莉花茶搭配
```

![实际输入截图：爆文链接、解析按钮、原文图片和用户要求](../../assets/readme/clone-input.png)

## 3. 生成了什么

先生成新的标题、正文和每页大纲，查看或修改后，再批量生成图片。

生成标题：**茉莉花茶一周不重样 🍵 办公桌养生指南**。
