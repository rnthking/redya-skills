## 输入主题

```text
写一篇关于果蔬脆片的种草图文，围绕办公室下午茶和追剧零食场景展开。
```

这是用于演示操作方式的输入示例。

## 关联商品

选择「商品图文」，关联自己的果蔬脆片商品档案。商品资料包括名称、卖点和素材图片，后续创作可以继续复用。

![商品原始素材示例](../../assets/readme/product-material.webp)

关联商品后，生成标题、正文和逐页大纲；可以修改文案与每页使用的素材，再批量生成配图。
